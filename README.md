# tongban-map — 통·리·반 지도 (공개 베타)

전국 읍면동을 선택해 통·행정리·반 경계를 그리고, JSON으로 저장·조회하는 정적 웹 도구입니다.

## 예시 웹사이트

- [지도 뷰어 열기](https://cbjworld.github.io/tongban-map/)
- [통·리·반 경계 편집기 열기](https://cbjworld.github.io/tongban-map/editor.html)

설치나 API 키 없이 브라우저에서 사용할 수 있습니다. 작성한 경계는 개인 PC의 **같은 브라우저에 지역별 자동 저장**됩니다. 서버나 GitHub·GitLab에는 작업 내용이 전송되지 않습니다. 중요한 작업은 JSON으로도 백업하세요.

## 실행

```sh
python -m http.server 8000
```

- http://localhost:8000/index.html : 읽기 전용 뷰어. 작성한 JSON을 불러오고 구역을 클릭해 이동합니다.
- http://localhost:8000/editor.html : 경계 그리기, 꼭짓점 편집, 필지 편입, JSON·CSV 내보내기.
- API 키 없이 OpenStreetMap 배경지도를 사용합니다. 지도 타일과 Leaflet CDN은 인터넷 연결이 필요합니다.
- 더블클릭으로 file://에서 열지 말고 HTTP 서버를 사용하세요.

## 기본 사용

1. 시도 → 시군구 → 읍면동을 선택합니다. 선택한 지역 경계와 보유 필지만 읽으며, 이전 지역의 데이터와 레이어는 교체합니다.
2. 동은 통·반, 읍·면은 행정리·반으로 자동 설정됩니다. 구분 선택에서 직접 바꿀 수도 있습니다.
3. 통/리 번호로 구역을 만들고 목록에서 이름을 입력합니다. 반은 해당 통/리에 속합니다. 법정리 원본을 행정리로 자동 변환하지 않습니다.
4. JSON을 PC에 저장합니다. 번호·이름·구분·지역 코드·외곽선·반 경계를 함께 저장합니다.
5. 뷰어에서 JSON을 불러옵니다. 예전 통 JSON도 읽지만 새 버전의 리 이름/구분/외곽선은 구버전 앱에서 유지되지 않을 수 있습니다.

점이 3개인 경계에서 점을 삭제하면 해당 조각을 삭제합니다. 남은 조각이 없으면 구역을 삭제합니다. 지역 변경과 JSON 덮어쓰기는 확인을 받으며, 잘못된 파일은 기존 작업을 유지합니다.

### 자동 저장·복구와 내 작업 보기

- 변경 후 약 0.3초 뒤 지역별로 자동 저장하고, 새로고침하면 마지막 지역과 통·리·반 경계·이름·외곽선·그리던 점을 복구합니다.
- 같은 사이트의 **뷰어**를 열면 내 저장본의 완성된 경계가 바로 표시됩니다. 열려 있는 뷰어에도 다른 탭의 저장이 반영됩니다. 미완성 점은 편집기에서만 복구합니다.
- 저장 위치는 PC의 브라우저 `localStorage`입니다. 임의의 폴더에 JSON 파일을 자동 생성하는 방식은 아닙니다. 같은 브라우저 프로필·사이트 주소에서만 공유되며, 다른 PC·브라우저·localhost·별도 배포 주소와는 공유되지 않습니다.
- 시크릿 모드 종료, 사이트 데이터 삭제, 브라우저 초기화 시 사라질 수 있습니다. 공용 PC의 같은 브라우저 프로필을 쓰는 사람은 저장본을 볼 수 있습니다.
- 용량 부족·손상·다른 탭의 변경을 감지하면 기존 저장본을 덮어쓰지 않고 경고합니다. 경고 시 JSON으로 백업한 뒤 새로고침하세요. 여러 편집기 탭에서 동시 작업하지 마세요.
- 가져온 **필지 원본**은 자동 저장하지 않습니다. 재시작 후 필지 파일은 다시 가져오되, 이미 편입한 결과 경계는 복구됩니다.

### 배포 동기화

GitHub `main`을 기준으로 GitHub Pages를 배포하고, `.github/workflows/gitlab-sync.yml`이 공공 GitLab `main`으로 같은 커밋을 전송합니다. 개인 작업 데이터가 아니라 **앱 소스만 동기화**합니다.

관리자는 GitLab `write_repository` 토큰을 GitHub 저장소의 Settings → Secrets and variables → Actions에 `GITLAB_PUSH_TOKEN`으로 등록해야 합니다. 토큰을 소스·JSON·채팅에 넣지 마세요. 개인 토큰은 해당 계정이 접근 가능한 다른 저장소에도 권한을 가질 수 있으므로 가능하면 저장소 전용 계정/토큰을 사용하세요.

토큰 만료 시 갱신하고 GitHub Actions의 **Sync public GitLab** 실행 결과를 확인하세요. 강제 푸시는 하지 않으며, GitLab에서 직접 수정해 이력이 갈라지면 먼저 GitHub에 병합해야 합니다. TLS 검증 실패도 우회하지 않고 실패 처리합니다. 포크 사용자는 워크플로의 대상 URL을 자기 저장소로 바꾸거나 동기화 워크플로를 제거하세요.

## 전국 필지 파일 가져오기

지역 선택 후 **필지 GeoJSON**을 누릅니다. 전국 일괄 자료가 아니라 해당 읍면동 규모로 잘라낸 파일을 사용하세요.

- UTF-8 GeoJSON FeatureCollection, WGS84(EPSG:4326), 경도·위도 순서.
- Polygon/MultiPolygon. 각 고리는 시작점과 끝점이 같아야 합니다.
- 최대 25MB, 10,000필지. 선택 지역과 겹치는 필지만 적용합니다.
- 속성: `jibun` 또는 `JIBUN`(지번), 선택적으로 `PNU`/`pnu`(19자리), `legal_name`(법정동·리명), `road_address`.
- 지번이 없고 PNU가 있으면 PNU로 지번을 생성합니다. 같은 지번은 PNU/법정동·리명으로 구분하세요.
- 파일은 업로드하지 않습니다. 지역을 바꾸면 메모리에서 교체되므로 필요할 때 다시 가져옵니다.
- 필지 편입 후 저장되는 JSON에는 결과 경계만 포함되고 필지 원본은 포함되지 않습니다.

### 브이월드 온라인 필지 조회

편집기의 **필지로 편입 · 이동 → 온라인 필지 조회**에서 본인이 발급받은 인증키를 입력하고 **연결 · 화면 조회**를 누릅니다. 키 등록 URL은 실제 사용하는 사이트 주소와 맞아야 합니다. 공개 예시 사이트는 `https://cbjworld.github.io/tongban-map/`입니다.

- 선택 지역과 현재 화면이 겹치는 범위만 조회하며, 지도 이동 후 자동 갱신합니다. API의 2㎢ 제한을 지키도록 넓은 화면은 확대를 요청합니다. 전국 일괄 다운로드는 하지 않습니다.
- 한 페이지 1,000건, 최대 10페이지까지 조회하고 중복 PNU를 제거합니다. 그 이상은 더 확대해야 합니다. 화면 밖·이전 지역 레이어는 제거하고 진행 중 요청은 취소합니다.
- 온라인 필지를 클릭하면 기존에 작성한 통·리·반의 소속을 중심점 기준으로 참고 표시합니다. **온라인 필지는 조회 전용**이며 편입·자동저장·JSON/CSV 내보내기에 넣지 않습니다. 파일로 가져온 필지 편입 기능은 그대로 유지합니다.
- 인증키는 페이지 메모리에만 유지하며 새로고침·연결 해제 시 없어집니다. 서버·저장소·자동저장에 보관하지 않습니다. 브라우저에서 직접 호출하므로 키는 브이월드로 전송되며 개발자 도구의 네트워크 화면에서는 확인할 수 있습니다.
- 브이월드의 JSONP 콜백으로 조회해 직접 fetch 호출의 CORS 제한을 피합니다. 공식 HTTPS API의 응답 스크립트만 실행하며, 별도 중계 서버로 키를 보내지 않습니다. 네트워크, 도메인 불일치, 인증키 오류 또는 사용량 제한으로 실패할 수 있습니다. 공개 코드에 키를 넣거나 브라우저 보안 설정을 해제하지 마세요.
- 브이월드 API 약관의 데이터 저장 제한 때문에 조회 결과를 편입·저장하는 기능은 제공기관의 허용 범위 확인 전에는 연결하지 않았습니다. MIT 코드 라이선스가 API 데이터의 이용조건을 대신하지 않습니다.

명세: [브이월드 연속지적도 2.0](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=cadastral). 원자료와 이용조건은 [DATA_SOURCES.md](DATA_SOURCES.md)를 확인하세요.

## 개인정보·정확도

### 주소로 통·리·반 찾기

1. 뷰어에서 같은 브라우저에 저장된 내 작업을 선택하거나 통·리·반 JSON을 불러옵니다. 지역 외곽선만으로는 소속을 판정할 수 없습니다.
2. **주소 검색 API 설정**에 브이월드 인증키를 입력합니다. **지오코더 API** 활용 권한과 현재 사이트에 맞는 등록 URL이 필요합니다. 예시 사이트 등록 URL은 `https://cbjworld.github.io/tongban-map/`입니다.
3. 도로명주소/지번주소를 선택하고 시·군·구를 포함한 전체 주소를 입력한 뒤 **주소 검색** 또는 Enter를 누릅니다. 지도에 위치와 해당 통·리·반을 표시합니다.

검색할 때 입력 주소와 인증키는 브이월드 공식 HTTPS API로 전송됩니다(JSONP). 앱의 자동저장·JSON 내보내기에는 검색 주소나 인증키를 넣지 않습니다. **검색 지우기 · 키 삭제**로 입력과 마커를 지울 수 있습니다.

판정은 **현재 불러온 지도**와 주소 API의 대표 좌표 기준입니다. 경계 5m 이내 또는 통·반 중첩은 **확인 필요**로 표시합니다. 반 도형이 없으면 반을 추정하지 않습니다. 대표점만 확인하므로 건물 전체가 경계를 넘는지, 주소의 동·층·호별 소속은 판정하지 못합니다. 공식 행정 소속을 보증하지 않으며 누락된 경계나 다른 지역의 지도에서는 소속이 없다고 나올 수 있습니다. 지역·지도 변경 시 이전 검색 결과를 지웁니다.

실제 인증키 조회는 별도 확인이 필요합니다. 자동 테스트는 가상 API 응답을 사용합니다.

통장·반장 이름/전화번호는 입력·내보내지 않습니다. 예전 파일의 해당 필드도 가져오지 않습니다. 통/리 이름에 개인정보를 입력하지 마세요.

동일 필지의 소속 표시는 중심점 기반의 참고 판정입니다. 복잡한 도형의 겹침 정리와 경계 정확성을 공적 원자료와 대조해야 합니다. 측량·권리관계 판단에 사용하지 마세요. 내려받은 복합 읍면동 외곽선의 꼭짓점 편집은 지원하지 않으며 새로 그리면 대체됩니다.

파일은 로컬 처리하지만 OSM 타일·Leaflet CDN 요청에는 IP와 지도 조회 범위 등 네트워크 정보가 전송됩니다. [OSM 타일 이용 정책](https://operations.osmfoundation.org/policies/tiles/)에 따라 사용하며, 대량 수집·오프라인 사전 저장 기능은 없습니다.

## 개발·검증

```sh
python check.py
npm install
npm test
python release.py
```

브라우저 테스트는 서버가 8000번에서 실행 중이고 Microsoft Edge가 설치된 환경을 사용합니다. 테스트 중 OSM 타일 요청은 차단합니다. 새 앱 의존성은 없고 Playwright는 개발 테스트용입니다.

다른 포트·하위 경로를 검증하려면 `BASE_URL` 환경변수를 지정합니다(예: `http://127.0.0.1:8001/tongban-map/`, 끝의 슬래시 포함).

화면 원본은 `src/editor_template.html`, `src/viewer_template.html`입니다. `python build.py`로 생성합니다. `prepare_regions.py`는 다운로드한 전국 GeoJSON 경로를 인자로 받아 분할합니다. 원본 옆에 LICENSE-DATA가 있어야 합니다.

`release.py`는 허용된 파일만 검사하고 상위 폴더에 `tongban-map-beta.zip`을 만듭니다. 비밀값 패턴·기존 개인정보 필드를 검사하지만 모든 민감정보를 식별하는 보안 감사는 아닙니다.
